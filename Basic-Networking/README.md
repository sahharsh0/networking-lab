# Basic Networking

This folder contains my initial Cisco Packet Tracer networking labs and experiments.

## Topics Covered

* Bus Topology
* Star Topology
* Basic VLAN Configuration

## Labs

### Bus Topology

Created a basic network using the bus topology to understand how devices can be connected through a common communication medium.

### Star Topology

Created a basic star topology where multiple devices are connected to a central switch.

### Basic VLAN Configuration

Configured basic VLANs on a Cisco switch and assigned ports to different VLANs to understand network segmentation.

## Tools Used

* Cisco Packet Tracer
